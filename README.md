# yikexinxing · yikexinxing

这是一个零依赖的静态个人博客首页，适合直接学习、修改和部署。

## 本地运行

直接双击 `index.html` 即可在浏览器打开。

如果使用 VS Code，可以安装 Live Server 后运行。

## 文件

- `index.html`：博客首页
- `style.css`：页面样式
